What delegation measures

The in-house Delegate Benchmark reports routing accuracy of 75.93% for Omni and 68.89% for Audio. A correct decision to use a capability is distinct from successful task completion; audio-only and audio–visual settings also have different inputs and difficulty levels. These results should be interpreted within their respective evaluation protocols.

How it works

Two models, one connected system

Two separately trained 9B models bring perception and speech into a continuous interaction loop.

Venus-Realtime-Omni supports audio–visual interaction; Venus-Realtime-Audio focuses on spoken dialogue. Both connect to Venus-Realtime-Harness, which handles delegated work while the frontend stays in the conversation.

Audio + video

Venus-Realtime-Omni

Follow visual events, respond proactively, and recall relevant context from long videos.

Audio

Venus-Realtime-Audio

Understand sound and speech, generate spoken responses, and distinguish interruptions from backchannels.

Background execution

Venus-Realtime-Harness

Route tasks to external capabilities and bring results back to the ongoing conversation.

System architecture

Two loops keep the conversation moving

The interaction loop keeps perception and speech active. The capability loop handles external reasoning and tools in parallel.

1

Capture the right context

Bind each request to its originating session and the evidence available when the request began.

2

Keep interaction running

Execute registered capabilities asynchronously while the frontend continues to perceive and speak.

3

Bring results back in time

Check result eligibility and coordinate delivery with the current conversation and speech playback.

Long-video memory

Keep useful context within reach

Venus-Realtime-Omni adds a training-free memory module for extended audio–visual sessions. It stores selected historical frames, retrieves evidence using relevance and novelty, and combines recalled context with recent observations.

The memory module is separate from the fine-tuned dialogue policy and requires no additional parameter updates.
